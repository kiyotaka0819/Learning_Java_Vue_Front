# Learning_Java_Vue_Front

Vue3 (Vite) を中心とした、フロントエンドとバックエンドの学習成果を統合したポータルリポジトリです。
単なる「写経」ではなく、**「実用性・保守性・可変性」**を追求したロジック実装をテーマにしております。

## Core Project: Jibun OS
Vue3で構築した仮想デスクトップ環境。
- **Window System**: z-index管理、ドラッグ＆ドロップ、リサイズ、Genieアニメーション。
- **Dynamic Content**: GitHub APIや外部リソースと連携した動的コンポーネント。
- **Automation**: GitHub ActionsによるREADMEの自動更新パイプライン。

## アプリケーション一覧
これまでの学習で構築した主要なアプリや。詳細は各リンク先を見てな。

| アプリ名 | 概要 | 技術スタック |
| :--- | :--- | :--- |
| **Jibun OS** | 仮想デスクトップ環境 | TS, Vue3, Web Storage |
| **名刺生成** | パーソナライズド名刺管理 | TS, Vue3 |
| **AI献立アドバイザー** | Gemini API連携のレシピ提案 | Gemini API, Vue3 |
| **お天気アドバイザー** | 季節連動ロジック搭載の天気予報 | API, JSON Logic |
| **TODO/ホワイトボード** | Supabase連携の永続化アプリ | Supabase, Canvas API |
| **ギター練習/コード譜** | GAS連携のスプレッドシートDB | GAS, Spreadsheet |
| **ポケモン図鑑** | PokeAPI連携のデータ検索 | Fetch API, Vue3 |
| **ニュースリーダー** | RSSフィード取得・表示 | RSS, Async/Await |

## 技術スタック
- **フロントエンド**: Vue3 (Composition API), TypeScript による型安全な開発。
- **バックエンド**: Java (Spring Boot), GAS を用いた API 構築。
- **Logic**: 共通化やデータの構造化（JSON管理）による、変更に強い設計。
- **CI/CD**: GitHub Actions を活用したワークフローの自動化。
